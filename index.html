dasimannan

Channel-management tool for the YouTube channel 다시 만난 사랑 (Love, Met Again)

What this application does

dasimannan is a private, single-purpose automation tool used by the owner of the YouTube channel 다시 만난 사랑 ("Love, Met Again"), a Korean-language channel that publishes original narrated love stories. The channel's videos are produced in advance, and dasimannan publishes them to the channel on a fixed schedule.

Using the YouTube Data API v3 with the channel owner's authorization, dasimannan:

  • reads the channel's identity and basic statistics to confirm it is operating on the correct channel;
  • uploads finished video files to that channel;
  • sets each video's title, description, tags and custom thumbnail;
  • schedules videos to become public at chosen times (scheduled publishing);
  • verifies that an upload completed and is scheduled as intended.

dasimannan is not a public product. It is not offered to other users, it operates only on the owner's own channel, and it does not access any other person's YouTube account or data.

Google API data

dasimannan requests two Google OAuth scopes: https://www.googleapis.com/auth/youtube and https://www.googleapis.com/auth/youtube.upload. How the data obtained through these scopes is used, stored and protected is described in the Privacy Policy.
