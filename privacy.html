Privacy Policy — dasimannan

Last updated: 24 October 2026

dasimannan ("the application") is a private channel-management tool operated by the owner of the YouTube channel 다시 만난 사랑 ("the channel owner"). This policy explains what data the application accesses through Google APIs, how that data is used and stored, and the choices available to the channel owner.

1. Data the application accesses

With the channel owner's authorization, the application accesses the following data through the YouTube Data API v3, and no other Google data:

  • Channel identity and statistics — channel ID, channel name, handle and country, and counts of subscribers, videos and views (scope: https://www.googleapis.com/auth/youtube).
  • Video upload and management data — the video files, titles, descriptions, tags, thumbnails and publishing schedules that the application itself submits to the channel, and the processing status of those uploads (scope: https://www.googleapis.com/auth/youtube.upload).

The application does not access Gmail, Google Drive, contacts, location, or any other Google service, and it does not access data belonging to any person other than the channel owner.

2. How the data is used

The accessed data is used for one purpose only: operating the channel owner's own YouTube channel. Specifically, to

  • confirm the application is acting on the correct channel;
  • upload videos produced by the channel owner and set their metadata and thumbnails;
  • schedule videos for publication and verify that uploads completed correctly.

The data is not used for advertising, profiling, or analytics about any individual, and it is not sold to anyone.

3. Data sharing

Google user data accessed by the application is not transferred or disclosed to any third party, except to Google itself as part of the YouTube API calls described above. The application has no other users and no downstream recipients.

4. Data storage and protection

  • OAuth credentials are stored in an encrypted credential vault. Application code never receives or records the raw credentials; requests are authenticated through a secure proxy at the moment each API call is made.
  • Video files and their metadata are stored on the channel owner's own systems for production purposes.
  • No Google user data is retained beyond what operating the channel requires. Channel statistics returned by the API are read on demand and are not accumulated into a database.

5. Data retention and deletion

The channel owner may revoke the application's access at any time from Google Account permissions or by emailing alihusnan418@gmail.com. On revocation or request, the stored OAuth credentials are deleted and the application can no longer access the account. Video files already published to the channel remain under the channel owner's control in YouTube Studio and can be removed there at any time.

6. Limited Use disclosure

dasimannan's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

If this policy changes, the updated version will be published at this address with a new "last updated" date before the changes take effect.
